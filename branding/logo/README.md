# Logo TemanBunda — "Pelukan Bersama"

Dua sosok — Bunda (pink) dan pendamping (ungu) — yang lengannya menyatu membentuk hati,
menjaga percik kehidupan baru (bintang) di tengahnya. Satu simbol untuk Mode Ibu dan Mode Suami.

| File | Pakai untuk |
|---|---|
| `temanbunda-icon.svg` | Simbol utama di latar terang (tanpa teks) |
| `temanbunda-icon-dark.svg` | Simbol di latar gelap |
| `temanbunda-app-icon.svg` | Favicon, ikon aplikasi, ikon sidebar (kotak membulat bergradasi) |
| `temanbunda-horizontal.svg` | Logo + tulisan di latar terang |
| `temanbunda-horizontal-dark.svg` | Logo + tulisan di latar gelap |
| `*-mono.svg` / `*-mono-white.svg` | Versi satu warna (charcoal / putih) |

Setiap SVG punya versi PNG beresolusi tinggi (ikon 1024 px, horizontal lebar 2048 px), latar transparan.
Tulisan memakai Manrope ExtraBold yang sudah dikonversi menjadi path, jadi tidak butuh font terpasang.

Konsep alternatif yang tidak dipilih ada di `konsep/` beserta `perbandingan-konsep.png`.

## Palet

Rose Pink `#CD3A69` → Deep Lavender `#7B5C9E` (gradasi utama) · Soft Pink `#E899A6` · Rose Purple `#996699` ·
Warm White `#FEF7F5` · Dark Charcoal `#2D2D2D`

## Aturan singkat

- Ukuran minimum simbol 24 px; di bawah 32 px pakai `temanbunda-app-icon` agar lebih terbaca.
- Jangan mengubah warna di luar palet, memutar, atau meregangkan logo.
- Beri ruang kosong di sekitar logo minimal setinggi kepala sosok (±1/6 tinggi simbol).
